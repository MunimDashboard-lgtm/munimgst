1. Sign in to publish

You can look at and edit everything without signing in. Signing in is only needed to publish.

How do I get a token? (one-time, 2 minutes)
  1. While signed in to GitHub as MunimDashboard-lgtm, open New fine-grained token.
  2. Name it Munim price admin and pick an expiry (for example 1 year).
  3. Under Repository access choose Only select repositories → munimgst.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

This token can only change files in the munimgst repository. Never share it. Anyone with it can change your prices.

What do the item types mean?
  1. Fixed fee – always charged (e.g. platform base).
  2. Per-unit – customer enters a quantity; only the amount above "included free" is charged at the rate.
  3. Choice list – customer picks one option (e.g. turnover band) and pays its fee.
  4. Yes/No add-on – charged only when ticked; can have a yearly and/or one-time fee.
